# Netflix Content Analysis

An exploratory data analysis project using **Python** and **Pandas** to analyze Netflix movies and TV shows. This project focuses on data cleaning, transformation, exploration, and extracting meaningful insights from a real-world dataset.

## Project Overview

Netflix has a large collection of movies and TV shows across different countries, genres, and release years. The goal of this project is to explore the Netflix content catalog and answer interesting questions using Pandas.

## Objectives

- Understand the structure of the Netflix dataset
- Clean and preprocess the data
- Handle missing values and inconsistencies
- Perform data exploration using Pandas
- Analyze trends in movies and TV shows
- Extract meaningful insights from the dataset

## Dataset

**Dataset Name:** Netflix TV Shows and Movies Dataset

The dataset contains information about Netflix titles, including:

- Title
- Type (Movie / TV Show)
- Director
- Cast
- Country
- Release Year
- Rating
- Duration
- Genre
- Date Added

## Technologies Used

- Python
- Pandas
- Jupyter Notebook

## Analysis Performed

The analysis includes:

- Loading and understanding the dataset
- Checking data types and missing values
- Data cleaning and preprocessing
- Filtering and sorting data
- Grouping and aggregation using Pandas
- Exploring movies vs TV shows distribution
- Analyzing release year trends
- Studying popular genres and countries
